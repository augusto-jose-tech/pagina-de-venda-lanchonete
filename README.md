# 🍔 Página de Vendas com Chatbot Integrado - Lanchonete

Esta é uma landing page profissional de alta conversão desenvolvida para o nicho de alimentação (lanchonete). O projeto conta com uma interface moderna e um chatbot integrado para demonstração de atendimento automatizado ao cliente.

🔗 **[CLIQUE AQUI PARA TESTAR O PROJETO ONLINE](https://github.io)**

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** - Estruturação e semântica da página
* **CSS3** - Design moderno, identidade visual e responsividade (mobile/desktop)
* **JavaScript** - Lógica e simulação do chatbot em tempo real

---

## 🎯 Funcionalidades em Destaque

* 🤖 **Atendimento Automatizado:** Chatbot funcional para simular a captação de pedidos.
* 📱 **Totalmente Responsivo:** Experiência otimizada para computadores e celulares.
* 🚀 **Foco em Conversão:** Estrutura pensada para retenção de clientes e vendas.
